# 星河科技 IT 服务台处理规范

文档编号：IT-SUPPORT-001  
版本：v1.0  
生效日期：2026-03-01  
负责部门：信息技术部

## 1. 网络无法连接

员工无法连接公司网络时，应先确认无线开关已打开，并检查设备是否连接到 `XH-Office` 网络。随后重新获取 IP 地址并重启设备网络适配器。

如果同一办公区域有三台以上设备同时无法连接，员工应在 IT 服务台提交“网络故障”工单，并填写办公地点、楼层、设备名称和开始故障时间。

## 2. 账号锁定

连续五次输入错误密码会触发账号锁定。员工可以在统一身份认证页面使用企业邮箱验证后自助解锁；自助解锁失败时，应联系 IT 服务台，由值班工程师核验员工工号后处理。

IT 服务台不会通过聊天工具索要完整密码或短信验证码。任何要求提供完整密码的消息都应按安全事件报告。

## 3. 电脑故障

硬件故障、系统无法启动或蓝屏问题需要提交“终端设备”工单。工单中应包含资产编号、故障现象、最近一次正常使用时间和必要的错误截图。

## 4. 服务时间和优先级

IT 服务台工作时间为工作日 09:00 至 18:00。影响单个员工的普通故障目标响应时间为四小时；影响一个部门的故障目标响应时间为一小时；影响全公司的故障按紧急事件处理。
